# tokenauth

安全方向小项目，`make test` 跑自检。

## 能力

- HMAC-SHA256 bearer 令牌，签名常量时间比较
- 过期校验带时钟容差（skew）
- nonce 重放缓存（环形，容量上界）
- 双密钥轮转：新签名用当前密钥，旧密钥仍可验签
- **撤销列表**（见下）

## 撤销列表

条目为 `(uid, nonce, expire)`，容量固定为 `REVOKE_MAX`，体积有硬上界。

- **按用户撤销**：`revoke_user(uid, now, ttl)`，条目 `nonce=0`，命中该用户的
  所有令牌（包括轮转后新签发的）。
- **按令牌撤销**：`revoke_token(token, now, ttl)`，解析令牌取出 `(uid, nonce)`
  后登记，只命中该一枚令牌；同 nonce 不同用户互不影响。
- **立即生效**：`verify` 在验签通过后、过期/重放记账之前先查撤销表，撤销后
  旧令牌立刻返回 `AUTH_REVOKED`，且不会写进重放缓存。
- **带过期自动清理**：每条带 `expire`，`verify` 读时惰性清理，也可显式
  `revoke_purge`；清理只删 `expire <= now` 的条目，未过期撤销不受影响。
  `ttl <= 0` 表示永久撤销（`expire=LONG_MAX`，任何 purge 都不删）。
- **重复登记**：同一 `(uid, nonce)` 已存在时原地续期，不新增条目。
- **与轮转共存**：撤销按身份 `(uid, nonce)` 匹配，与签名密钥无关，轮转后
  依然有效。
- **表满策略**：有限 TTL 的新条目只能淘汰严格更早过期的条目，同 TTL 拒绝
  （防同 TTL 撤销洪流搅动表）；永久撤销可占用一个有限 TTL 的槽，但永久条目
  自身永不被淘汰。
